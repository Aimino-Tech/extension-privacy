# Aimino Browser Connect — pilot privacy notice
Effective 24 November 2026. Applies to the Browser Connect 0.5.0 pilot only; this release requires a compatible BrowserSkill daemon and is not a public ChatGPT connection. Publisher and contact: Aimino Tech GmbH, Germany, info@aimino.de, https://aimino.de/.

## Data and purpose
The extension connects a browser to a user-selected compatible daemon or gateway so the connected agent can carry out browser tasks. Connection is off by default in the pilot. When enabled, data accessible to the connected agent may include website text/HTML, screenshots, tab and window identifiers, URLs and titles, visible or supplied form values, interaction state and page changes, including personal or financial information displayed on signed-in pages. The selected daemon may receive results and issue actions. Optional website debugging can record requests and responses, headers/bodies, console messages, actions and field values; optional video recording captures the selected task tab. Explicit screenshot/video export, local file transfer and optional audit features also exist. Pairing configuration, device identifiers, credentials and preferences are used to establish and restore the selected connection. No independent advertising, analytics or tracking service is added by the pilot overlay. The extension uses broad host access and debugger permission to carry out browser operations; this is powerful access, not a read-only extension. Only pair with a daemon you trust.

## Recipients, transfer and storage
The pilot does not include an Aimino-hosted consumer gateway or an automatic ChatGPT connection. By default the daemon endpoint is on the same computer. If you configure a remote gateway, task data can be sent to that endpoint via authenticated encrypted transport, and the agent/gateway operator may retain or further process results under its own terms. A local daemon can also be connected to an external AI service by the user. Review those services' terms before using them with personal data. Aimino does not receive or sell task data through this pilot. Browser storage retains preferences and pairing credentials; optional debugging and video data are stored locally, and optional audit metadata is stored by the selected daemon. Upstream defaults are 30 days for stopped debug captures and audit records, 24 hours for temporary task recordings, subject to storage limits. Exported files and agent/gateway copies can outlive the browser session and are not deleted automatically by disconnect or uninstall. The upstream implementation and detailed storage/feature description are available at https://github.com/Tencent/BrowserSkill/blob/feb601ca9be5c3276660b2c28ea6d3c946567d1b/apps/extension/PRIVACY.md.

## User control and support
Use the connection switch or Disconnect button to disable the selected connection. Review native pairing, task and tab-borrow settings and any debugging or recording before granting access. Remove saved pairing credentials or history through the applicable extension controls; clearing extension data or uninstalling removes extension-local data but not exported files or copies held by the selected daemon, agent or third parties. Contact info@aimino.de for privacy questions; do not send confidential page contents or credentials to support. If you contact support, information you choose to send is handled separately to respond. This notice is limited to the current developer pilot; a different hosted or ChatGPT-connected release needs its own reviewed disclosures.
